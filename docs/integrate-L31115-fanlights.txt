## How Integrate stores a fanlight
# A TransomPart in the frame's `dividers` array (as mullions): thickness 27 (profiled; 67 overall with two 20 stops),
# offset = height of the opening ABOVE it (356), offset2 = opening below (503 on a 980 frame), stop sizes 20 top / 20 bottom.
# Openings are tagged by row: A1 = above the transom, A2 = below. The board's Explorer labels the top casement "Fanlight".
# One CillPart (width = internal width). Validation shows a WARNING on every fanlight with the 83 bottom rail:
# "Fanlight bottom rail should be reduced to 62mm externally" — the drawings below keep 83 (as Integrate's own drawing 1/10).
# Fanlight sash = opening - 2 x 4 clearance: 958 x 348 on a 1040 frame.

## Surround lengths (read 12 Oct)
# Integrate's board stores each drawing's surround list (`surround` on DrawingItemPart: qty, length in mm,
# lockToItemWidth/Height 0). The price lines then use those stored lengths. So there are TWO roundings:
#   1. the board snaps the rule's length (1000 x width/height + 100) UP to the next 10 mm;
#   2. the price uses that length to the NEAREST 0.1 m, halves up.
