## How Integrate stores a French casement
# No mullion. The frame holds ONE FrenchCasementPart (the pair) holding a LeftFrenchCasementSashPart (A1) and a
# RightFrenchCasementSashPart (B1); in FR2 the pair sits under a transom as A2/B2 with the fanlight A1 above.
# FrenchCasementPart{thickness 57, typeId 7 (open out), clearance 4 all round, midRail 130 ("Overall Meeting Stile"),
#   gapBetweenMeetingStiles 4, meetingStileSplitId 12, sashSplitId 12}
# Left sash{op 17 LH, topHeight 62, leftWidth 62, rightWidth 63 (its meeting stile), bottom 83}
# Right sash{op 18 RH, topHeight 62, leftWidth 63 (meeting stile), rightWidth 62, bottom 83, isMasterLeaf true}
#   (meeting stile 63 each = (midRail 130 - gap 4) / 2). French sashes are 57 THICK, not 54. Live GlazePro profile 2
#   already holds frenchCasementPart.thickness 57, midRail 130, gapBetweenMeetingStiles 4, clearances 4.
# Sash size: height = opening - 8; width = (opening width - 8 - gap 4) / 2 each.
#   FR1: internal 1125 x 1219 -> each sash 556.5 x 1211 (Integrate draws 556.5).
#   FR2: frame 899 x 1499, transom 27 at offset 304 / offset2 1074, internal 825 x 1405; fanlight A1 (CasementSashPart,
#        54 thick, top hung, 62/62/62/83) 825 x 304 -> 817 x 296; pair below 825 x 1074 -> each 406.5 x 1066.
# Cill: ONE CillPart, width = internal width (1125 / 825); volume full frame width as other casements.
