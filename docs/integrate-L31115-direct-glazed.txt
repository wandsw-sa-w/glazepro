## How Integrate stores these (GetDrawing /SurveySystem/GetDrawing/Lead/L31115/{item}/{drawingNo}/Edit)
# - AssemblyFramePart is the only frame. Mullions and transoms are NOT child parts: they live in the frame's
#   `dividers` array (MullionPart / TransomPart with thickness, offset, offset2, stop size, startDivider/endDivider).
# - The frame's children are a flat list of openings, each tagged matrixIndex = column letter + row number
#   (A1 = left/top, B1 = next column, A2 = next row down), followed by one CillPart per bottom-row opening
#   (cill width = that opening's internal width).
# - An opening is EITHER a CasementSashPart (with its own GlassPart child) OR a GlassPart directly in the frame.
#   A GlassPart directly under the frame IS a direct glazed unit (board label "Direct Glazed Unit"). It carries the
#   opening-level fields itself: toBeReplaced=1, matrixIndex, shoulderHeight, thickness 56, mechanicalClearance 20 all
#   round, hiddenInRebate 18 all round, glazingRebateWidth 20 (casement sash glass: rebate 16, no clearance fields).
# - Board: select an opening -> "Change ..." -> Product list: Direct Glazed Unit, Panel to Frame, Pair of Sashes,
#   Casement, French Casement, Floating Transom Casement, Door, French Door, Stable Door.
# - Casement operationId: 11 Fix, 15 Top Hung, 16 Bottom Hung, 17 Left Hand Hung, 18 Right Hand Hung.
#   A FIXED casement sash is a CasementSashPart with operationId 11 (still a sash: sash timber, sash machining, sash finishing).
#   Casement typeId 7 = "Open Out / Flush with Stops Internally". Sash 54 thick, head 62, stiles 62, bottom rail 83, clearance 4.
# - Frame (flush casement template): jambs 37, head 47, cill 47, frame depth 96, cill depth 128, mullion 27 (profiled; 67 overall,
#   20 machined from mullion), frame stop 40.
# - Item type follows the content: itemTypeId 3 while the frame holds any casement sash; it switched to 25 (and newSashes=false)
#   when every opening became a direct glazed unit. Validation adds "ADD QUOTE NOTE: Due to direct glazed panes, some fixing
#   points may be situated on visible parts of the frame..." whenever a direct glazed unit is present.
# - The ironmongery list is the surveyor's explicit list; changing openings does NOT change it (all four drawings below still
#   carry the original handle/hinge/shootbolt set, priced as listed). "Default for Casement Window" did not change it either.

## Nathan's decisions (9 Oct 2026)
# 1. Direct-glazed-only frames: MATCH Integrate (no frame timber / cill / LTW consumables lines when the frame has no casement sash).
#    Known gap to fix later in the pricing rules of both systems — not a GlazePro difference.
# 2. Labour rule "Base Direct Glazed Unit in Frame" (Direct Glazed group, sort 10) never fires (needs bi-fold AND door AND casement):
#    MATCH Integrate exactly. Flag for a later rule change ("should apply when the frame also has a casement or door").
# 3. Ironmongery: GlazePro's board DEFAULTS the list per opening when openings change (opening casements get handles/hinges/
#    shootbolts; fixed casement sashes and direct glazed units get none); the surveyor can still edit the list. This is a board
#    behaviour difference from Integrate (which never changes the list) — record in docs/integrate-differences.md when built.
#    Prices still follow whatever list is stored, so benchmarks K-N are checked with Integrate's stored list.
