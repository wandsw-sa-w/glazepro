## How Integrate stores a divider that stops at another divider
# Mullions and transoms are in the frame's `dividers` array, each with an id and startDivider / endDivider:
#   '0' = runs to the frame; otherwise the id of the divider it starts / ends at.
# TC1: Mullion{startDivider = the transom's id} — the mullion runs from the transom DOWN to the cill (bottom row only);
#      the transom runs jamb to jamb. TC1's transom also carries outerThickness '32' (TC2/TC3 transoms do not).
# TC2: both '0' — the mullion runs head to cill and the transom jamb to jamb (they cross).
# TC3: Transom{startDivider = the mullion's id} — the transom runs from the mullion to the RIGHT jamb (column B only);
#      the mullion runs head to cill.
# Openings keep Integrate's matrix labels: a spanning opening takes its top-left slot (TC1 fanlight = A1 across both
# columns; TC3 full-height opener = A1 down both rows) and the empty slot simply has no part.
# One CillPart per bottom-row opening (TC1 493 + 511, TC2 590 + 608, TC3 543 + 561); cill VOLUME = full frame width.
